HR Analytics Dashboard (Microsoft Excel)
Project Overview
The HR Analytics Dashboard is an interactive Excel-based reporting
project built to analyze employee information and present key workforce
insights in one place. It uses employee, department, and performance
data with PivotTables, PivotCharts, KPI summaries, and slicers.

The dashboard helps users explore employee headcount, employment status,
demographics, salary distribution, and performance ratings.
Dashboard Highlights

Visualizations
The dashboard includes charts for:
1. Employees by Department -- compares employee headcount across
   HR, Finance, IT, Sales, and Marketing.
2. Employee Status -- shows the Active and Inactive employee split.
3. Department-wise Salary Distribution -- compares salary totals
   across departments.
4. Employees by Gender -- displays the gender distribution.
5. Employees by City -- compares employee counts across Bengaluru,
   Delhi, Kolkata, Mumbai, and Pune.
6. Employees by Manager -- compares the employee counts associated
   with department managers.
Interactive Slicers
Use the available slicers to filter connected PivotTables and charts by:
- Gender
- Department Name
- Employment Status
Select one or more values in a slicer to explore a particular employee
group. Clear the slicer filter to return to the overall view.

How to Use
1. Download or open utkarsh_dashboard.xlsx in Microsoft Excel.
2. Enable editing if Excel opens the workbook in Protected View.
3. Open the dashboard sheet to view the KPIs and charts.
4. Use the Gender, Department Name, and Status slicers to filter the
   report.
5. Review the updated KPIs and visualizations after applying filters.
6. When the source data is changed, use Data → Refresh All to
   refresh PivotTables and connected charts.

Project Objective
The objective is to transform raw HR data into an easy-to-understand
interactive dashboard. It demonstrates practical Excel data-analysis
skills and supports workforce reporting and data-driven HR decisions.
