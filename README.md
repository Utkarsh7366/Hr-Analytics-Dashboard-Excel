# HR Dashboard

## 📊 Project Overview
The **HR Dashboard** is an Excel-based Human Resources analytics project designed to analyze employee information, departmental distribution, employee status, salaries, and performance metrics.

The workbook combines employee master data with department and performance information and uses **Pivot Tables / Excel dashboard elements** to summarize key HR insights.

## 🎯 Objectives
- Analyze the overall employee workforce.
- Compare employees across different departments.
- Track **Active vs Inactive** employee status.
- Analyze employee age and salary information.
- Review employee performance ratings.
- Understand department-wise workforce distribution.
- Support HR decision-making through summarized data and KPIs.

## 📁 Workbook Structure

### 1. Dashboard
The main dashboard area intended for presenting HR KPIs and visual summaries.

### 2. Pivot Table
Contains summarized HR metrics and KPI calculations, including:
- Total employee count
- Average age
- Active employee count
- Average performance rating
- Average salary
- Other pivot-based summaries

### 3. Employees
Employee master data containing fields such as:
- Employee ID
- First Name
- Last Name
- Gender
- Age
- Department ID
- Job Title
- Joining/Employee Date
- Salary
- City
- Email
- Status
- Department Name
- Year
- Manager
- Rating

### 4. Departments
Department master data containing:
- Department ID
- Department Name
- Manager

Departments included in the workbook:
- HR
- Finance
- IT
- Sales
- Marketing

### 5. Performance
Employee performance data containing:
- Employee ID
- Review Year
- Rating
- Training Hours
- Projects Completed

## 🚀 How to Use
1. Open `HR_dashboard.xlsx` in Microsoft Excel.
2. Go to the **Dashboard** sheet for the main HR overview.
3. Use the **Pivot Table** sheet to review summarized calculations.
4. Use the **Employees**, **Departments**, and **Performance** sheets to inspect the underlying data.
5. Refresh Pivot Tables if the source data is updated.
